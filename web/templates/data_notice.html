1. Data Sources and Upstream Attribution

Contrail aggregates, normalizes, and redistributes near-real-time global aviation telemetry strictly on an "as-is" basis for educational, academic research, and non-commercial personal projects. All underlying data remains the exclusive intellectual property of the respective upstream providers.

3. Terms of Service & Acceptable Use Policy

Please review the binding acceptable use policies below. Use the language tabs to switch between English, Simplified Chinese, and Japanese versions.

1

Strictly Non-Commercial Use Only

Data provided by Contrail is licensed exclusively for non-commercial educational, personal hobby, or academic research activities. You may not sell, sublicense, repackage, charge fees for, or incorporate this data into any commercial service, paid application, or advertisement-monetized platform.

2

Mandatory Downstream Attribution

When redistributing, publishing, visualizing, or embedding data retrieved from Contrail, you must retain the upstream attribution metadata (as delivered in the API attribution and source fields) and link to this notice.

3

No Bulk Database Scraping or Mirroring

Automated high-frequency mass crawling to reconstruct a standalone clone, offline mirror, or competing commercial database is strictly prohibited.

4

No Life-Critical or Operational Navigation Use

Telemetry is non-official, uncertified, and may be delayed, intermittent, or inaccurate. It must never be used for flight planning, air traffic control, actual aircraft navigation, or any life-safety decision.

5

API Key Throttling and Revocation

Contrail reserves the right to throttle, suspend, or revoke any API key or user account found to violate these terms or upstream provider guidelines without prior notice.

6

Commercial Licensing Direct Inquiries

Contrail cannot and will not grant commercial licenses. Commercial entities must apply directly to the original data providers (The OpenSky Network, adsb.lol, PlaneBase, etc.) for commercial data agreements.

1

严格仅限非商业用途

Contrail 提供的所有航空数据仅供学习、学术科研、个人爱好项目使用。严禁出售、转授权数据，亦不得将数据用于任何收费或营利性产品、商业软件、增值服务或广告变现平台。

2

保留数据来源署名

在公开展示、发布、转发或调用本 API 数据时，必须保留原始数据来源署名（参见 API 响应中的 attribution 与 source 字段），并附上本合规声明链接。

3

禁止批量抓取建库

严禁通过高频抓取或全量脱机建立商业竞争性或替代性的第三方公开数据库与镜像站。

4

非官方数据安全免责

所有数据均为非官方接收聚合数据，可能存在延迟、偶发抖动或传感器误差，严禁用于实际航行管制、飞行领航、空中防撞或任何生命安全攸关场景。

5

违规限流与吊销机制

Contrail 团队有权在发现违规商业化、过度滥用或违反上游协议时，随时对相关 API Key 或账户进行限制或即时吊销。

6

商业授权申请指引

Contrail 不提供任何商业授权或商业付费版 Key。如有商业需求，请直接向各原始数据源（如 The OpenSky Network、adsb.lol 等）申请合法授权。

1

非商用利用限定

Contrail から提供されるすべての航空データは、教育、学術研究、個人プロジェクトのみを対象としています。データの転売、サブライセンス、有料製品・サービスへの組み込み、広告収益化目的での利用は固く禁止されています。

2

帰属情報の保持

データを公開、転送、または利用する際は、API レスポンスに含まれるデータソースの帰属情報（attribution および source フィールド）を必ず維持してください。

3

大量スクレイピングの禁止

独自の代替データベースを構築するための過剰なスクレイピングやミラーリングは禁止されています。

4

航法・安全用途の禁止

データは非公式のものであり、遅延や誤差が含まれる可能性があります。航空機の運航、航空管制、航法、または生命の安全に関わる判断に使用することはできません。

5

API キーの取り消し

利用規約に違反した場合、または上流プロバイダのポリシーに抵触した場合、事前の通知なしに API キーを制限または失効させることがあります。

6

商用利用について

Contrail では商用ライセンスの発行を行っていません。商用利用を希望される場合は、各データソース（The OpenSky Network、adsb.lol など）に直接申請してください。

Strict Compliance Notice

Commercial use is strictly prohibited by upstream data sources. Do not apply for keys or deploy Contrail in commercial production environments. Violations result in permanent blacklist and notification to upstream network administrators.
