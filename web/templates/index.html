API Quickstart & Authentication

All live data endpoints require a provisioned API key passed via the X-API-Key HTTP header or ?api_key= query parameter. Rate limits apply per key: 60 RPM, 1,000 RPH, and 10,000 requests/day.

curl -H "X-API-Key: YOUR_API_KEY" "https://airline.api.veyino.org/api/v1/flights?limit=10"

Contrail API Endpoints Reference

GET /api/v1/flights

Query live aircraft vectors with filters (callsign, hex, squawk, origin, dest, bbox, emergency, diverting).

curl -H "X-API-Key: YOUR_KEY" "https://airline.api.veyino.org/api/v1/flights?limit=20&emergency=true"

GET /api/v1/emergencies

Stream live emergency aircraft broadcasting squawk 7700, 7600, or 7500.

curl -H "X-API-Key: YOUR_KEY" "https://airline.api.veyino.org/api/v1/emergencies"

GET /api/v1/diversions

Retrieve flights algorithmically flagged as deviating from destination trajectory.

curl -H "X-API-Key: YOUR_KEY" "https://airline.api.veyino.org/api/v1/diversions"

POST /api/v1/query

Custom JSON query engine supporting complex geospatial and altitude filtering.

curl -X POST -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \ -d '{"filters":{"min_altitude_ft":30000,"origin_icao":"ZSPD"},"limit":10}' \ "https://airline.api.veyino.org/api/v1/query"

Contrail API Terms of Service

1. Strictly Non-Commercial: Learning, research, and personal hobby projects only. No reselling, commercial monetization, or advertising integration.

2. Attribution Retention: Must preserve upstream attribution metadata (attribution & source fields) in any public presentation.

3. No Bulk Mirroring: Mass scraping to construct competing commercial databases is prohibited.

4. No Navigation/Safety Use: Unofficial data, not for flight planning or ATC decisions.

5. Revocation: Keys violating terms will be throttled or permanently revoked.

6. Commercial Licensing: Upstream providers do not permit commercial redistribution. Inquire directly with OpenSky, adsb.lol, PlaneBase.
